# ML course, NTUST, Fall 2026 - Homework 3
Ce projet a pour but d'apprendre a réaliser un traitement de données en utilisant des méthodes de deep learning.

Il comprends trois sous-objectifs:
* Développer un classifier pour le dataset MNIST.
* Développer un classifier pour le dataset du spooky challenge de Kaggle.
* Réaliser un rapport de deux pages en anglais pour présenter le travail effectué (voir détails dans le dossier doc, fichier hw3_2026).

Je profite de ce projet pour atteindre un autre objectif personnel: apprendre à utiliser un workflow d'IA agentique, en utilisant Codex pour m'aider dans ce travail. Le but va être de voir comment cet outil fonctionne, quelles sont ses limites, à quel point il est autonome, etc.
